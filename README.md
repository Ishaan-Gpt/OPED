# OPED - AI Powered Blackboard

This is the frontend codebase for the OPED digital blackboard, powered by React, Vite, and Remotion.

## Getting Started

1. Run `pnpm install`
2. Run `pnpm run dev`
3. Open `http://localhost:3000`

## Architecture

This frontend is backed by a complete AWS CDK infrastructure (Lambda, DynamoDB, API Gateway, Fargate) located in the `/services` folder.
